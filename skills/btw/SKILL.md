# btw 侧问通道

主会话正忙着长任务、而你冒出一个不相关的问题时，**不要打断主会话**，用 `/btw`。

- `/btw <问题>` — 带主会话上下文快照的侧问线程（默认）。适合"这个函数为什么这么写""刚才那个报错常见于什么场景"这类与当前仓库相关的问题。
- `/btw:t <问题>` — 无上下文的旁路线程。适合与仓库无关的闲问（概念解释、常识、发散讨论）。
- 连续追问直接再发 `/btw`，共享线程历史；想换话题重开线程用 `/btw:new`。
- `/btw:save` — 把当前线程整理成结构化笔记追加到 `~/btw-notes.md`（路径可配）。每次问答本身已自动追加原始记录。

注意：侧线没有工具，答不了需要读文件/跑命令的问题；这类问题等主 agent 空了直接问主会话。模型与思考等级在 `~/.pi/agent/btw.json` 配置。
